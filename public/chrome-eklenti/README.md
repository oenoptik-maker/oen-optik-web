# OEN Optik - UTS Aktarım Chrome Eklentisi

## Kurulum:
1. Chrome'da `chrome://extensions` adresine gidin
2. Sağ üstteki "Geliştirici modu"nu açın
3. "Paketimemiş uzantıyı yükle" butonuna tıklayın
4. Bu klasörü seçin (`chrome-eklenti`)

## Kullanım:
1. UTS sayfasını açın (utsuygulama.saglik.gov.tr)
2. Ürünleri işaretleyin (checkbox)
3. Chrome araç çubuğundaki OEN Optik ikonuna tıklayın
4. "Ürünleri Aktar" butonuna tıklayın
5. "OEN Optik'i Aç" butonuna tıklayın
6. Ürünler otomatik olarak uygulamaya yüklenir
